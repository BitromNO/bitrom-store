# Bitrom App Store (Community)

Community App Store for umbrelOS, powered by [getumbrel/umbrel-community-app-store](https://github.com/getumbrel/umbrel-community-app-store).

Apps:
- `bitrom-miner` — Solo CPU Bitcoin miner with a live web dashboard.

Add this store on your Umbrel: **Settings → App Store → Add Community App Store** → `https://github.com/BitromNO/bitrom-store` (or the `.git` URL).
